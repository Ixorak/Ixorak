### Hi, I'm Ixorak 👋

I design **AI agents, automations and custom tools**, 3D in the browser, websites and games.
French-Canadian, based near Lausanne, Switzerland. I work solo and remotely.

**My method:** I design the system and set the rules, AI agents write the code, automated tests and a second agent check every step, and I approve what gets delivered. That is how I move fast without letting quality slip.
